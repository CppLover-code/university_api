Почему Custom User — правильный подход

Многие новички делают ошибку:

❌ используют стандартный User
❌ потом пытаются добавить role

И начинается боль с миграциями.

Лучше сделать правильно сразу

✅ custom user
✅ расширяемая архитектура
✅ готово для JWT
✅ готово для permissions
✅ production-style structure

**************************************************************
Serializers

Serializer переводит: Python object <-> JSON

Зачем это нужно?
Frontend не понимает Django объекты. Frontend понимает: JSON

**************************************************************
ViewSets
ViewSet автоматически создает:

Метод	            Что делает
GET	                получить данные
POST	            создать
PUT	                обновить
DELETE	            удалить

Без ViewSet

Пришлось бы писать вручную:
get()
post()
put()
delete()
DRF делает это автоматически!!!!!
