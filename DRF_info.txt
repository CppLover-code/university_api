**************************************************************
Serializers

Serializer переводит: Python object <-> JSON

Зачем это нужно?
Frontend не понимает Django объекты. Frontend понимает: JSON

**************************************************************
ViewSets
ViewSet автоматически создает:

Метод	            Что делает
GET	                получить данные
POST	            создать
PUT	                обновить
DELETE	            удалить

Без ViewSet

Пришлось бы писать вручную:
get()
post()
put()
delete()
DRF делает это автоматически!!!!!

viewsets.ModelViewSet - Это готовый CRUD.
Он автоматически умеет:
Метод	    URL
GET	        список
GET /id	    один объект
POST	    создание
PUT	        обновление
DELETE	    удаление

queryset - Какие данные брать из базы.
serializer_class - Как превращать данные в JSON.
